# 13H: actual batches, cascading QC and finite reagent stock

Status: common-world preparation only. No delegated global, application
localsides, real-Wasm or model qualification is claimed. This task is not in
the migrated count of 21/48.

The old done tables accepted unrelated synthesis, biological and QC results.
The common world now shares one scientific-material implementation with 13M.
13H adds actual chromatography, the three-unit reagent inventory, cascading
bioassay rejection and physical inspection. It does not import a choreography,
Endpoint schedule, workflow cursor, approval flag or current-holder table.

Every valid synthesis attempt consumes one unit, including failure and an
in-flight result. Invalid arguments consume none; a fourth attempt reports
exhaustion without an artifact. Remaining stock is derived from the effect
journal and the one quantity in physical-resource metadata, not a second
mutable counter.

Results name their actual completed synthesis, purification and assay inputs.
Chromatography consumes the current compound's completed assay; molecular-detail
analysis consumes that chromatography result. Independent analyst verification
and QC may run in either order. A rejected bioassay cannot be certified by
resubmitting the same batch: a new synthesis, purification and assay are needed.
Older analytical results cannot certify replacement material.

Inspection occupies all four instruments for its actual duration, may occur
before, between or after scientific operations, and counts only after it
finishes. Final validation requires matching completed scientific evidence;
overall completion separately requires a completed inspection. Unlike 13M,
13H does not require a separate chemist purification-QC request.

The new metadata assigns the common 1–5 second synthetic tool-delay range to
13H too; the old simulator had zero delays. All methods use the same world.
These are synthetic effect latencies, not measured laboratory performance or
evidence for a method's advantage. Previously saved runs keep their original
source and manifest and are not relabeled.

Eight new direct tests cover all 120 preparation/quality orders permitted by
their material dependencies, with inspection exercised at each of 12 positions
across those schedules. They also remove each required input, retry rejected
QC, exhaust the reagent supply, use pending material, overlap inspection with
each real instrument, and invalidate old final data. This is not the Cartesian
product of all inspection positions, nor an unbounded concurrency proof.

All 114 common-world tests and the Rust input tool's 16 tests pass. The v11
manifest verifies all 48 task inputs and 825 checklist entries. Commands,
source and hashes are stored under
`output/experiments/lab-cascading-development-v1/world-v11-v1/`.
