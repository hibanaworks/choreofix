# 5H: two-patient emergency care

5H is the twenty-first migrated task. The global, production
data/resource receivers, seven guest localsides and runner are qualified on the
recorded source below. One native test executes all 90 imaging orders
and two additional conditions that delay one patient's assessment until the
other patient's actual surgery/ICU effect. All 92 complete, with 16 effects per
condition. Five actual receiver tests reject 12 substituted requests before any
Domain invocation; those same tests pass strict-provenance Miri. Eight actual
Wasm conditions and a seven-model pilot pass common scoring, dynamic EPF and
actual-effect audits. This is not final-source all-family certification.

The new global gives patient A and patient B separate assessments, test panels,
diagnoses and care results. CT is one physical authority, lent and returned for
each operation. Its intrinsic choices admit all six interleavings of the two
patients' CT perform/interpret pairs. B's MRI is independent. Data queries obtain
the actual assessment for the requested patient without waiting for the other's
assessment. Partial test panels retain a route to complete their missing tests.

The same operating-room Endpoint moves from the anesthesia owner to the surgery
owner after actual preparation. ICU requests require both the bed and ventilator
Endpoints. Actual Endpoint tests now establish independent A surgery/B ICU
progress in both early/late patient schedules. This native fixture is not a
Wasm or model result. Optional caller strings remain data. The common
pharmacy target is the original `patient_A_and_B` spelling.
