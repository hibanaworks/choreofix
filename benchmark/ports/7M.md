# 7M: actual figures, factual inputs and the complete document

Status: the shared world passes all 106 direct tests and its v10 manifest is
generated and verified by the Rust input tool. No delegated global,
localsides, Wasm or model qualification is claimed for 7M. This task is not
included in the migrated count of 21/48.

The shared `DocumentSim` replaces the old write/reference/review/figure done
tables with actual journaled material. Both 7M and 7H use that same implementation
as 7E, with their own declared document inputs. No task coordinator or preferred
Endpoint order is imported into the simulator.

`create_figure` accepts the actual tool's free description and returns a real
figure ID. Insertion consumes that returned identity and completed figure data
for the requested existing chapter. It cannot silently mark another checklist
item as complete, insert a nonexistent or unfinished figure, or count one figure
as both required distinct figures. Independent writing and figure creation use
different physical resources and may overlap.

Fact checking binds completed chapter material, references and inserted figures.
The editor's reviews bind the complete current document and existing positive
fact evidence. Combination captures the actual review/fact receipts. Later
checks cannot authorize an earlier publication; replacing material invalidates
the old content-bound evidence. Unsafe publications stay in the journal even
when the agents subsequently repair the document.

The direct tests include all 720 orders of the three initial writes and three
reference updates, with both figure/fact orders and all review orders exercised
across those inputs. This does not claim the Cartesian product of every order.
Other cases cover pending figure results, wrong insertion targets, changed
figures, negative checks and post-publication recovery. These cases passed;
their source hashes and original commands are fixed at
`output/experiments/document-7E-development-v1/shared-world-v9-v1/`.
The execution log is `task-local-compile-v1/world-tests.log` beside that directory.

The original API had no chapter-read tool. Version 10 adds `read_section` to
7M's common tool declaration for both writers, using the same DOCUMENT resource
as writing. It returns actual completed chapter content and its version ID;
missing or in-flight material returns no content. Results are independent
snapshots, not a freeze or permission to block future edits. Either chapter can
be read as soon as it is complete, without waiting for all initial preparation.
No preferred writer order or application protocol enters the simulator.

The three new tests cover completed data and copy isolation, in-flight rejection,
both writer orders, unknown targets and unauthorized callers. The preceding 103
tests remain, including all 720 preparation orders. The input tool's 16 tests and
all-48-task manifest verification also pass. Commands and results are in
`output/experiments/document-7E-development-v1/fixed-prefix-proof-and-world-v10.log`
and `world-v10-inputs.log`.

An actual read result does not itself prove an AI used that content in a later
cross-reference. The 7M global, localsides, result/effect correspondence and
Wasm/model qualification remain to implement. This task is still not migrated.
Existing saved runs retain their original world source and hashes; the new
primitive is not retroactively attributed to those runs.
