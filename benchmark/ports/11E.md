# 11E procedure and source-bound qualification

The target remains the original four jobs, two capacity-one workstations and
three model participants. The common simulator stays free to execute any call:
it records actual machine conflicts and completed job data, and grades the
supervisor's actual report. No ChoreoFix order is copied into that scorer.

The ChoreoFix global has distinct affine LATHE and MILL Endpoints. Four further
Endpoints identify the four actual request continuations, not additional
machines. A receiver chooses the first user from the request it actually
received, lends the appropriate request Endpoint and reports Ready or Busy.
Busy returns an ordinary recoverable error to wash, leaving that actual request
Endpoint with its caller so the model can choose its other job. Repeated requests
start each rolled visit; a service cannot autonomously restart a retired query.
Ready does not retire an elastic retry. The caller returns the query Endpoint
before receiving the workstation Endpoint. The receiver accepts a late retry
crossing Ready until that actual return, and never reissues the accepted RPC.

The WASI localsides write each send/recv/offer and resource return directly. A
technician completes two actual jobs, choosing either first and receiving Busy
feedback without blocking its shell on an occupied machine. Its two stored
optional values are real owned request Endpoints. There is no done flag, holder
table, job manager or second filesystem. Wrong-job input is rejected before a
business message. A duplicate borrowed request is rejected by the Endpoint;
only its documented pre-admission unavailable result permits recovery.

Each technician's one wash guest executes its two job effects sequentially,
as described by the original task. The global also permits independent resource
operations through distinct views; we do not claim a global theorem enforcing
an additional per-technician capacity-one constraint. The shared task's physical
capacity constraints are the two workstations. This explicit procedural scope
is recorded before any 11E common-world, model or scored execution.

The supervisor consumes four actual completed results before its one report
request, and the report receiver validates all four values and the actual
response. Its public arguments remain `{}`. An early supervisor command may
wait for those results. This is the supervisor's stated task dependency, not a
simulator permission rule.

Twenty native test functions (seven task and thirteen shared-shell) pass,
including all twenty-four job orders, asymmetric readiness, disjoint-machine
overlap, Busy/retry/switching, a late first retry, and retries crossing both a
parked and a consumed Ready. Each job effect occurs once. The real production
lathe receiver rejects four wrong-job, extra-field or malformed wire payloads
before any effect across two runtimes; that test also passes strict-provenance
Miri. The separate shared RPC borrow boundary passes Miri. Neither establishes
whole-Wasm memory safety or macOS FFI verification.

The earlier `wasi-v4` source passed 32 actual-Wasm conditions. Its first live
three-participant pilot then failed after one actual job: the new task localside
could skip the first mandatory Retry/Busy roll visit when the earlier RPC or
workstation return completed before any retry. The core correctly rejected the
incomplete fragment. Both original records remain preserved. The repair keeps
the actual returned Endpoint while serving that first retry without blocking
the earlier job result; it adds no workflow flag, global message or core/model
relaxation. The contended matrix now includes both early and late first retries.

orders, four adversarial recovery inputs, and eight normal-delay contended

conditions show two overlapping pairs of distinct-machine effects and no
same-machine overlap. Their recorded test barriers are mechanism fixtures, not
model-trial inputs. The fixed-source guard peaks at 1,094,189,056 bytes.
