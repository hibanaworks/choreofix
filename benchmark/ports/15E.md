# 15E · Wafer fabrication

The integration engineer receives the reference-wafer Endpoint. Four ChoreoFS
paths on that Endpoint let the wash guest mount the wafer, measure its alignment,
and run the film-integrity and etch-uniformity checks in either order. Once the
stepper has submitted the mount, it lends the stage Endpoint to metrology. The
measurement can start while the mount call is outstanding. Metrology keeps the
stage after a failed measurement and returns it after a successful one.

Three real Wasm runs cover film first, etch first, and a failed overlay
measurement followed by a retry on the same load. They also exercise both
orders of reading the mount and measurement replies. The retry case attempts a
spot check immediately after the failed measurement. The shell receives an
error and can retry the measurement. The audit checks each measurement against
its own received request, simulator invocation, physical result and reply.
Both spot checks name the same mount and successful measurement receipts.

The [alignment measurements](../../analysis/15e-wafer-alignment.json) record
those three runs with one scripted wash guest.

The [lot-disposition runs](../../analysis/15e-wafer-disposition.json) add
three wash guests. After both spot checks, the integration engineer writes a
disposition with the two inspection receipts to each fabrication engineer.
Each recipient reads its own ChoreoFS inbox. All six send orders completed.
In three runs the sender finished all three writes before any recipient read;
the guests then read in reverse order. The other three runs consumed each
message before the next send. The audit matched the delivered bytes to the
two inspection receipts in each run. The common simulator scored the physical
work separately and recorded completion with zero violations in all six runs.

The [process validation trials](../../analysis/15e-wafer-validation.json)
add the process controller as a fifth wash guest. Its monitoring file sends
the cross-reference request to the monitor Endpoint. The controller reads the
simulator result and sends it to the three fabrication engineers and the
integration engineer. Each reads the result from their own ChoreoFS inbox.
An attempt to announce validation before checking failed at the shell. In the
injected monitoring failure case, the same attempt also failed after the
negative result. The controller retried, then delivered the successful result
to all four recipients. The six trials passed EPF and common-world scoring.

The ordinary quality workflow builds the runtime with `--build-wasi` and runs
`oracle::tests::wash_uses_the_same_reference_wafer_for_both_spot_checks`.
The five guests ran scripted shell commands. The upstream fabrication and
metrology operations and two post-validation instrument calls still used
simulator fixtures. Six-agent live qualification remains open.

cover the previous binary, in which the fixture supplied the mount and alignment.
