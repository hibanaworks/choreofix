# 15E · Wafer fabrication

The integration engineer can use the same aligned reference wafer for the
film-integrity and etch-uniformity checks in either order. The engineer's wash
guest receives the wafer Endpoint. ChoreoFS binds both instrument paths to that
Endpoint. Each instrument consumes the typed request before calling the common
simulator and sends the actual result back. After the checks the guest returns
the wafer to the aligner.

Two scripted runs on the same executable exercised the two orders. In each
run, a premature nonblocking read and a write naming the wrong instrument's
process returned shell errors at each of the two paths. The shell then issued
the correct requests. The audit matched both committed receives to their
simulator arguments, the replies to the scored results, and both results to
the same two alignment receipts. Each run produced 763 EPF records and a
complete simulator score with zero violations. The first 17 simulator calls,
including the alignment work, were fixture inputs. Two of the 19 scored
effects came from the guest. The experiment used one scripted guest and zero
model calls. The [measurements](../../analysis/15e-wafer-spot-checks.json)
include the journal, binary and source hashes.

The ordinary quality workflow builds the runtime with `--build-wasi` and runs
`oracle::tests::wash_uses_the_same_reference_wafer_for_both_spot_checks`.
The six-engineer qualification remains open. It requires the fabrication and
in-situ measurements, transfer of material and validation results, and final lot
disposition to pass through the projected participants in the same run.
