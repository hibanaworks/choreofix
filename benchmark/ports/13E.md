Three scientists perform eight original operations. Raw-material analysis
produces the input to purification. Prepared cells support calibration. The
actual purified compound and prepared/calibrated cells support the bioassay.
Molecular analysis and separation verification independently consume that same
completed assay. Final validation consumes both quality results for the same
compound and assay. The original common world has no injected business failures.

Each scientist has one autonomous wash Wasm instance. Each operation file owns
its actual typed Endpoint. Its close is the original scientific request; there
is no generic request file followed by path/phase dispatch. The scientist
localsides own actual specimen/measurement data and send the exact request and
actual inputs through the real instrument Endpoint before an effect. Both hops,
actual results and file replies are in the same global and visible directly in
their localsides. There is no host workflow, permission table, stage flag,
Endpoint wrapper, second progress machine or alternative effect path.

The spectrometer and centrifuge are unique Endpoints issued by their physical
integration and transferred to their I/O owners in this global. Each I/O owner
consumes one real request at a time, checks its arguments/material data and
returns the actual effect result. Their Endpoints return to the issuer at
completion. Scientists may request either available instrument without a
host-selected next loan. Completed instrument results, retained as actual data,
also prevent substituting fabricated earlier measurements.

Unlike the retired global's fixed preparation rounds, raw-analysis/purification
and cell-preparation/calibration are independent chains. All six causal
interleavings of those four operations remain available. The two quality
operations are also independent. The source does not force the written
description's cross-instrument list order. The common world remains unchanged
and does not inspect the choreography or select a preferred total schedule.

preparation orders, either quality submission order and omitted/free culture
text, plus one normal-delay concurrent case. The latter checks actual overlapping
instrument effects without barriers or invalid-input preprocessing. Other cases
exercise early, malformed and duplicate requests followed by valid work.
Optional culture text is arbitrary string data, including chunked Unicode input.
