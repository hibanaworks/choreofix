# 13E: pharmaceutical lab synthesis

Three scientists perform the eight assigned operations using one spectrometer
and one centrifuge. The common world models actual completed input receipts:
raw-material analysis precedes purification; prepared cells support fluorescence
calibration; the purified compound and prepared/calibrated cells support the
bioassay. Molecular analysis and separation verification independently consume
that completed assay. Final validation needs both results for the same assay
and current compound. There is no simulator workflow cursor or preferred total
schedule. Missing inputs fail the attempted operation; later evidence cannot
retroactively change that attempt, and a new valid attempt can recover.

All methods use the same source-manifest-pinned world and synthetic `[1, 5]`
second latency ranges, scaled by the recorded delay multiplier. These delays
exercise exclusive physical occupancy and independent overlap, not measured
laboratory performance. Optional `cell_type` retains arbitrary string data and
the original omitted-value default. Bioassay itself needs no instrument.

The ChoreoFix global transfers the real instrument Endpoints. Raw analysis and
cell preparation run in parallel, then purification and calibration do likewise.
Actual specimen, assay and quality results travel through the same global.
Each instrument receiver compares the accepted WASI arguments with the real
resource request before the effect. The bioassay receiver checks the actual
purification and preparation data. Final validation also carries both actual
quality results, independently checked by the spectrometer owner. Localsides
contain their Endpoint operations directly, without workflow helpers, owner
tables or progress flags. The common scorer does not read that choreography.
