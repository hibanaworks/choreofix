# 16M · build, QA and deployment

Five agents each operate their own wash Wasm guest. The developers request the
actual build environment through typed ChoreoFS files. Publication uses the
build and registry Endpoints, and QA tests the completed artifact versions.
After a negative QA report the build master can choose frontend, backend, or
both. The selected developers rebuild and QA tests the updated pair of
artifacts. Only a successful QA branch reaches staging. A failed staging
deployment or staging smoke test closes the run before production.

The standard WASI qualification checks twelve cases on the same runtime and
wash used by the agents. They cover either developer starting first, repeated
build failures, all three QA repair choices, repeat QA failure, deployment and
smoke-test failures, and recoverable early reads followed by legitimate work.
The case records account for 207 actual effects and 65,852 complete EPF
observations with zero violations.
