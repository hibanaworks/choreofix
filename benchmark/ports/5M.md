## Protocol and file boundary

One global projects 38 roles. Twenty-three actual operation/data files use
five affine Endpoint views, explicitly loaned to the five guest VMs. Each
file request is the actual typed business message. Paths and byte buffers do
not dispatch a later operation or hold workflow permissions. Localsides drive
resource loans, requests, actual replies and returns directly.

Panels support combined, split, reversed and repeated requests while incomplete.
Their actual completed data and resource Endpoints move once to the conference
owner. This custody transfer and the file result are inside the completed
branch. Completed resources are not loaned back for another test. CT and MRI
remain independent; both physical scanners retain their original argument
schemas. Referral, findings, candidate and summaries are actual message reads.

Each guest owns its operation view. A read that requires its own unperformed
operation returns a recoverable WASI error; normal reads can still wait for
other participants' actual data. The shell chooses commands freely. There is
no host command recipe, stage dispatcher, progress flag or alternate filesystem.
No core, runtime or WASI production source changed for this port.

The actual-Wasm suite passes all nine conditions: all six causal imaging
orders, combined panels, invalid/repeated partial requests, and concurrent
CT/MRI requests. It retains premature-read recovery and post-completion duplicate
rejection. Every run passes complete EPF, one-use request/effect/reply matching
and neutral common scoring with zero violations. The normal-delay concurrency

rejects 360 record mutations; these are not 360 runtime attacks. The suite takes
185.50 seconds and at most 1,420,148,736 descendant bytes.

The same runtime's five-Luna/xhigh live pilot finishes in 75.243086458 seconds,

Its 7,504 producer records, actual arguments, effects, replies and common outcome

overlaps and at most five simultaneous model turns. Same-tool CT/MRI overlap is
zero in this pilot. Eleven model/source/run-record mutations are rejected.
Two data tests, 54 runner tests and application/runner Clippy pass. No application
Miri was run. Development uses stable Rust 1.100.0 with forbidden long const
evaluation. The successful build took 35.48 seconds and 538,640,384 descendant bytes.

An earlier seven-view pilot timed out on a candidate read before the ER's own

pooled with the successful pilot. The initial five-view global was rejected
because a completed file result was outside its branch; the corrected global

The common world grades actual patient inputs and physical conflicts for every
