# 8E API migration and integration test

Three agents use wash to submit a schema migration, a backend implementation
and an integration test. The global orders the three effects and delivers the
test result to both developers. Each agent chooses its own shell commands.
The scripted trials also exercise correction after malformed input and rereading
the actual result.

The ChoreoFS files bind directly to typed messages. The backend executes the
request it receives. The migration and test receivers compare their resource
request against the submitted bytes and receive the database or test Endpoint
before invoking the simulator. [Global and file bindings](../../src/tasks/api/choreofs)

On the 21 November build, all three scripted depths passed the EPF and effect
audits. The auditors rejected all 54 record mutations, including substitutions
of submitted bytes and published results. The separate three-agent live trials
used the same binary. At depth 0 the common simulator scored the task complete.
At depth 2 it returned the injected terminal test failure. Both developers read
the result in both trials. [Run evidence](../../analysis/8e-received-effects.json)
