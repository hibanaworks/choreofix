`/service/rebuild`. Writing a listed module name to that same file requests its rebuild.
An unknown or currently valid module returns the eligible candidates and a diagnostic on
the next read. The final verified candidate still arrives at `/service/candidate` after
the editing Endpoints are returned.

## Current implementation

`src/tasks/cascading_build/` defines one global and its 30 projected
roles. Five actual wash guests use ChoreoFS files bound to owned FILE Endpoints.
Typed file requests participate in the same global as the actual business
requests; no generic close handler selects a later business operation.

All six initial builder permutations remain available. The executable accepts
no initial-order argument. Its actual typed file requests choose implicit source
branches through distinct logical views owned by the same compiler actor. A
builder receives that request first, then both actual resource Endpoints in parallel,
sends the exact admitted arguments to the compiler and both resources, receives
the actual result and returns both resources. Updates, test feedback,
reconsideration and the final outcome have distinct received message contracts.
The guest may choose shell commands, private work and legal retries freely.
Common metadata/private-I/O branches occur once, outside the order choice.
The next builder's actual request precedes the overlapping previous-object test
and resource loan. The real object notification is inside that selected branch,
before its test/build fork; the test participant therefore learns the choice
before its outgoing operation.

The tester receives the actual object, exposes that object to its guest and
receives a module-specific typed test request. A completed build can be tested
while another build proceeds. The compiler retains actual objects and completed
test receipts. The integrator receives these data and selects a stale or failed
object for rebuilding. It does not maintain an owner table or a workflow flag.

Before linking, the editing Endpoints leave the repair continuation. The
integrator receives all three, supplies the actual successful candidate to its
guest and accepts the typed link request. Both resources and admitted arguments
must match before a domain effect; returned objects and test receipts must also
match the actual current data.

This benchmark's compiler is a synthetic object/material world, **not a real
compiler invocation**. Its common simulator checks actual input contents,
completed tests and the published object occurrences independently of the
choreography. No simulator procedure was changed for this direct-file rewrite.
