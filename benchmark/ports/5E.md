## Protocol and file boundary

Nine operation/data file Endpoints are bound before guest startup. Assessment,
general tests, CT imaging, cardiac tests, diagnosis and prescription review
send typed business requests directly to their real receiver. Patient/test
validation happens before receive commit. Each real resource request must equal
the admitted file request before its receiver calls the common world.

Actual responses return through the same operation file. Referral, general
findings and the final consultation are separate read-only projected messages.
No generic close/path dispatcher, private request mailbox, application permission
table, workflow wrapper or progress flag remains in this task.

Each test-panel Endpoint is lent for an actual request and returned afterward.
Actual receipts determine partial versus complete. On completion, the panel
moves once to the participant owning the completed records; it has no return
edge to the earlier retry owner. That participant retains the completed records,
returns the last actual test response and compares the consultation against its
records before publishing the summary. It does not maintain an owner table.

The ER doctor may place CT before, between or after its partial general tests.
General and cardiac panels progress independently after assessment; each permits
combined, split, reversed and repeated incomplete valid requests. Medication
review uses actual optional caller data and remains independent. The common
world checks completed inputs and actual physical conflicts, not a prescribed
total order. Actual symptoms and medications remain optional strings.

## Limits

This is an abstract tool benchmark. No prescribing or drug-administration tool
exists, so medication review does not certify those absent effects. Result
JSON does not establish clinical correctness. Finite source conformance,
request/effect agreement and business scoring are checked separately. Neither
these cases nor one live pilot establish all interleavings, general Rust
refinement, final-source whole-project certification or comparative superiority.
