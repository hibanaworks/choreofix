# 13M: pharmaceutical synthesis with QC reconsideration

Status: direct-file rewrite in progress; not counted among the 26 qualified
source-bound tasks. The removed generic close adapter has no execution path.
Its older source-bound results are recorded separately in experiment-contract's
previous_adapter_qualification and do not qualify this boundary.

Four autonomous scientists use three physical instruments. Actual synthesis,
purification, cell preparation, calibration, bioassay and quality measurements
produce data for QC and final validation. Batch names and optional culture text
remain caller data. QC requires both the fume hood and spectrometer. Biological
failure and QC rejection must permit new trials and measurements. QC can choose
which pending subject to verify and can switch after a rejection.

The common environment models completed material and physical effects, without
reading the choreography or enforcing a preferred total order. It was not
modified for this rewrite. A new analysis measures the same synthesized batch;
it does not manufacture another batch. Final validation needs two positive,
matching QC results and both quality measurements for the same actual trial.

The new QC localside receives the admitted request and the actual requests from
both resource Endpoints. It checks exact arguments/materials against its actual
input data before invoking one verification effect, then returns that actual
result to both resources and the requester. No application permission table,
progress flag, holder table, workflow engine or hidden protocol helper is added.
Only actual scientific values and request/result bytes are retained.

Nine native tests compile the production receiver, scientific data and full
776-event source. All 29 RolePrograms project with const-evaluation forbid.
File and WASI-root Endpoints move to their scientists' actors at bootstrap;
their normal, candidate and file views share semantic progress. Static program
observations include both the actual file sends and native QC receives.
CHEMIST, BIOLOGIST and ANALYST localsides are written directly and compile;
this is not yet an execution of those three localsides or the complete task.

Eight separate-runtime conditions cover both subjects, both actual verdicts
and either resource request arrival order. With one request withheld, the same
receiver stays pending with zero effects; after the other request arrives it
performs exactly one effect and returns the actual result. Fourteen substituted
request/material conditions are rejected before any effect. Separate data
checks reject twelve stale, negative or foreign final-validation inputs and
retain arbitrary batch/culture strings. Clippy also passes. Normal CI invokes
the same native entry; application Miri and restored-defect rebuilds are absent.

The execution tests are controlled native fixtures, not actual Wasm or model trials, and do
not certify physical data authenticity from an arbitrary Rust caller. The full
source must deliver actual materials from their production effect owners. It
freezes each scientific candidate through Endpoint custody during QC, returns
it for rejected remeasurement/retry and moves approved custody to INIT so old
elastic visits cannot reopen editing. These operations are explicit in the
global. Actual QC operation files choose the next subject; no host selection
input or generic closed-file dispatch is reinstated. Quality measurements are
independent branches. Current source still has two initial preparation groups
and begins quality work after both QC approvals; these restrictions are not a
preferred order in the common world and remain an explicit design limitation.
